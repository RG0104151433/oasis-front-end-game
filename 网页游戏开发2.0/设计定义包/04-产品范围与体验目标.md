## 1. 首发可玩范围

| 项 | 结论 |
|---|---|
| 协议结局 | 四协议：继承（inherit）、穹顶托管（dome）、公共能源（public_energy）、玩家公约（charter） |
| 扩展线 | 首发一条 X 线（阿尔忒弥斯 X1–X4）；K/M 线作为主线节点已定稿，随主线一并落地 |
| 第零线 | 首发可玩（Q2②=是）：维护窗口、倒计时、离线湾均进入首发 |
| 内容包 | 第五协议、第六协议完整演出作为“第一内容包”，在 G1 预留扩展点，首发实现入口与前置判定 |
| 多周目 | 首发不做多周目系统（Q5=A）；同周目可再入、不写失败态、不提示、通关后不自动继承 |

## 2. 玩家每分钟体验目标

| 幕 | 体验目标 | 核心操作 |
|---|---|---|
| 序章 · 家的残响 | 建立现实困境（债务 4,312、母亲失踪）与 21:47 符号 | 探索 home/balcony，收集线索 |
| 绿洲入口与年鉴馆 | 虚拟层规则感；接收“无署名邀请” | 进入 data_vortex → oasis → library_gate |
| 三钥线 | 智慧之钥、过程之钥、勇气之钥；每把钥匙对应一幕主题 | 图书馆 / 翻转道路 / 迷雾迷宫 |
| 第零线维护窗口 | 隐藏线质感；EPHEMERAL 维护标记；倒计时压力 | 图书馆调查点 → 终局「下行：离线湾」 |
| 现实收尾 | 北区水泵站；P0-1 母亲最后 10 分钟 | 强制演出，不可跳过 |
| 终局裁决 | 四协议选择；角色去向 20 条 reviews | palace_memory 热区 + 四结局 |

## 3. 非目标

- 不做移动端适配（Q4=桌面浏览器）；
- 不做多人/联机；
- 不做多周目系统（Q5=A）；
- 首发不实现第五/第六协议的完整演出（作为第一内容包）；
- 不做移动端支付/广告。

## 4. 发布矩阵

| 版本 | 内容 | 资源边界 |
|---|---|---|
| 首发 | 四协议 + X 线 + K/M 主线 + 第零线维护窗口 | Q6=R1 全部首发场景重绘；统一新美术 |
| 第一内容包 | 第五协议、第六协议完整演出 | 新增结局槽、reviews、音频、章节卡、预载链 |
| 后续 | 多周目、移动端、新支线 | 视首发验收结果决定 |

## 5. 与 Q6=R1 的联动

Q6 裁定为“全部首发场景重绘”，因此：

- 主线、支线、终局、第零线、隐藏线场景统一使用新美术；
- 场景美术 bible（风格、色板、透视、像素/分辨率、UI 叠层规则）由 D 轨在 `09-内容补全与资源manifest.md` 交付；
- 唯一场景 manifest 含场景 id、背景图、尺寸/格式/命名、热区坐标、程序化兜底；
- 新场景与 `cfg.maps` / `ROUTE_DATA` / 章节卡 / 预载链 / 氛围音映射表；
- 中英场景名、章节 ordinal、成就/回放条目；
- 资源失败兜底与加载预算；
- 验收用例：缺图、错图、热区错位、双语缺失、预载失败。
