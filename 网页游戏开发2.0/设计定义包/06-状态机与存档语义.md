- 版本：v1.0（正式 DDP 骨架）

- 主责：B 轨（结局/规则/状态）

## 1. 必答问题

1. 结局状态 `entered/chosen/completed/eligible/seen/done` 的转移条件与 UI 表现；
2. 第零线维护窗口瞬态清理与重入条件（Q5=A）；
3. 旧档补算：`zero_backup_tape`、`fifth_arc_completed`、`sixth_arc_sealed` 缺失时默认行为；
4. 多周目继承白名单（首发不做，但预留字段）；
5. 存档版本升级策略（旧档加载不报错）。

## 2. 状态转移

| 状态 | 进入条件 | 退出条件 |
|---|---|---|
| `entered` | 进入宫殿且满足该结局 requirements | 选择其他结局或离开宫殿 |
| `chosen` | 点击该结局 | 播放完结局演出 |
| `completed` | 结局演出结束并写入 reviews | 不可退出（终态） |
| `eligible` | 满足 requirements | requirements 失效（如 clue 被清除） |
| `seen` | 回看结局文本 | 不可退出（终态） |
| `done` | 该结局已达成 | 不可退出（终态） |

## 3. 第零线维护窗口（Q5=A）

- 瞬态：`zero_countdown_active`（倒计时进行中）；
- 重入条件：回到 `finale_transition` 且 `zero_backup_tape` 存在；
- 不写：`zero_missed`、`sixth_arc_sealed`；
- 不清：已获得的 `zero_backup_tape` clue；
- 清：倒计时瞬态、临时 UI 标记。

## 4. 存档结构

| 层 | 内容 |
|---|---|
| `Save.flags` | `Set<string>`，flag 默认 false |
| `Save.clues` | `{id, source}[]`，clue 默认未发现 |
| `Save.endings` | `{id, status, seenAt, doneAt}[]` |
| `Save.normalizeProgress` | 旧档补算唯一入口 |

## 5. 旧档补算

| 缺失字段 | 默认值 | 备注 |
|---|---|---|
| `zero_backup_tape` | false | 第零线未进入 |
| `fifth_arc_completed` | false | 第五协议不可达成 |
| `sixth_arc_sealed` | false | 第六协议不可达成 |
| `kira_signature_echo_public` | 未发现 | charter reviews 缺一条 |
| `morrow_witness_token` | 未发现 | M 线徽记缺失 |

- [ ] 第零线维护窗口规则与 Q5=A 一致；
- [ ] 旧档补算在 `Store.normalizeProgress` 完成；
- [ ] 决策人已确认。
