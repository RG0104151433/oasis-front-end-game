## 2. 首发可玩范围

| 项 | 结论 |
|---|---|
| 协议结局 | 四协议：继承（inherit）、穹顶托管（public_energy）、公共能源（public_energy*）、玩家公约（charter） |
| 扩展线 | 首发一条 X 线（阿尔忒弥斯 X1–X4）；K/M 线作为主线节点已定稿，随主线一并落地 |
| 内容包 | 第五协议、第六协议、第零线作为“第一内容包”，在 G1 预留扩展点，首发不实现 |
| 多周目 | 首发不做多周目系统（New Game+）；Q5 推荐“同周目可再入、不写失败态、不提示、通关后不自动继承” |

> 注：`public_energy` 指“穹顶托管/公共能源”结局在剧本中的具体命名需以 DDP 真值表为准，此处为占位。

## 3. 玩家每分钟体验目标

| 幕 | 体验目标 | 核心操作 |
|---|---|---|
| 序章 · 家的残响 | 建立现实困境（债务 4,312、母亲失踪）与 21:47 符号 | 探索 home/balcony，收集线索 |
| 绿洲入口与年鉴馆 | 虚拟层规则感；接收“无署名邀请” | 进入 data_vortex → oasis → library_gate |
| 三钥线 | 智慧之钥、过程之钥、勇气之钥；每把钥匙对应一幕主题 | 图书馆 / 翻转道路 / 迷雾迷宫 |
| 现实收尾 | 北区水泵站；P0-1 母亲最后 10 分钟 | 强制演出，不可跳过 |
| 终局裁决 | 四协议选择；角色去向 20 条 reviews | palace_memory 热区 + 四结局 |

## 4. 非目标

- 不做移动端适配（Q4 已定桌面浏览器）；
- 不做多人/联机；
- 不做移动端支付/广告；
- 不做多周目系统；
- 首发不做第五/第六/第零线的完整可玩版本。
